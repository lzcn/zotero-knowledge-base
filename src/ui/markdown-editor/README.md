# Archived Markdown editor

The custom editor from commit `082348de1ab6a4afb34e036ab1b1d804f549970e` is retained for development only. It is not loaded by the UI, compiled, or included in the XPI. The original page scripts, Tiptap adapter, live math nodes and styling are preserved here; dependency versions are recorded in `dependencies.json`.

The active editor uses Zotero native notes. This archive is not a supported alternate format and must not be wired into native note saving without an explicit conversion design.
