# Knowledge Base

<img src="addon/content/icons/icon-256.png" width="64" height="64" alt="Knowledge Base" />

[English](README.md) | **简体中文**

在 Zotero 中管理笔记、整理标签、发现相似条目。

## 安装

需要 Zotero 10。从 [Releases](https://github.com/lzcn/zotero-knowledge-base/releases/latest) 下载 XPI。在**工具**菜单中打开**插件**，选择**从文件安装插件**，然后重启 Zotero。

## 使用

在**工具**菜单中打开**知识库**，或使用文献库、PDF 工具栏中的按钮。

- **笔记：** 自动发现现有 Zotero 笔记，直接关联原文，并将父条目作为来源。右键选择**在知识库中打开**，双击保持 Zotero 默认行为。支持原生或 Markdown 编辑、自动保存。简洁的类型控件可切换文献笔记、原子笔记、思考笔记和实体（默认），不自动添加类型标签。用 `[[ID]]` 连接笔记，支持搜索、图谱和来源／上级标签继承。设置中提供**管理模板…**。
- **推荐标签：** 统一按相关度展示最多六个高置信主题，新标签与已有标签使用不同颜色标记；勾选后添加到当前论文。顶部操作栏提供“添加所选标签”和右侧的“标签管理”。标签管理保留明确的合并、单个标签重命名和删除操作，暂不提供批量命名格式。以逗号分隔的排除标签共用于推荐、标签管理和笔记展示，排除不会删除 Zotero 原标签。
- **相似条目：** 在本地查找相似文献，默认包含无全文条目，不自动连接笔记。macOS 语义检索会自动下载所需文件。

三个切换页共用同一个文献库运行时，各窗口共享索引和结果。启动时直接恢复完成后的检索缓存；未变文献复用向量和已保存结果，新增或变化的文献在后台更新。升级后首次启动会从已有索引生成新的缓存。设置页仅在节标题上使用少量颜色区分，缓存状态保持简短。

图谱可按笔记类型切换，或查看父条目。父条目图只包含已有笔记的文献，复用本地检索缓存，提高相关度门槛，并只保留双方都排进前三的相似关系。笔记图显示层级和引用，不混入来源节点。链接列表只展示标题，ID 保留在悬浮提示和复制入口中。

编辑器在正文上方显示来源、上级笔记和标签，可就地修改。点击上级笔记标题跳转，旁边的铅笔用于更换上级。过长标题保持单行，悬停可查看完整标题。底部状态栏提供类型和可直接编辑、复制的 ID；长 ID 保持紧凑，编辑时仍可操作完整内容。原生与 Markdown 编辑共用更宽、随窗口伸展的正文区域和紧凑间距。单击知识库左侧笔记在当前界面查看，双击在独立窗口打开。图谱操作保留在顶部工具栏和列表右键菜单中。

## 备份

正文使用 Zotero 同步。ID、层级和链接保存在本机 `knowledge-base.sqlite` 数据库中。退出 Zotero 后备份其数据目录，包括此数据库和 `knowledge-base/` 文件夹。

资源统一由存储模块管理，在 Zotero 数据目录中的布局如下：

```text
knowledge-base.sqlite
knowledge-base/
  assets/
  cache/
    similar-items/
    coreml/minilm-l6-v2/
  models/minilm-l6-v2/
  runtime/onnx/
```

图片放在 `assets/`；检索与模型编译缓存放在 `cache/`；下载资源放在 `models/` 和 `runtime/`。目标目录不存在时会接续使用旧检索和 Core ML 缓存。独立 Related Work 的数据保留在原处。`-wal`、`-shm` 由 SQLite 自动管理。

schema 12 和 13 在同一事务中升级，原普通笔记归入实体。已有分类和标签保留。自动发现时保留原始正文、标签与位置，只读文献库保持只读。

## 开发

需要 Node.js 22.13+（22.x）或 24+。

```sh
npm ci
npm run check
npm run build
```

产物：`dist/zotero-knowledge-base.xpi`。
