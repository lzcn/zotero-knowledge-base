在 Zotero 中管理笔记、整理标签、发现相似条目。需要 Zotero 10。

## 功能

在**工具**菜单、文献库或 PDF 工具栏中打开**知识库**。

### 笔记

在条目侧栏右键笔记，选择**在知识库中打开**；或在设置中启用**原生笔记使用知识库编辑器**，在侧栏、标签页或窗口中编辑。用富文本或 Markdown 写作，修改自动保存。在笔记上方设置**来源**（Zotero 条目）、**上级**（铅笔可搜索笔记）和**标签**。类型可选文献、原子、思考或实体；底栏显示类型和可编辑 ID，模板在设置中管理。**增强 → 数学预览**在笔记卡片和 PDF 批注中显示公式。

### 双链

输入 `[[` 查找笔记。默认候选来自当前段落、标题、标签和已有连接；继续输入会在整个笔记库搜索。用 ↑/↓ 选择，Enter 或 Tab 插入，Escape 关闭。链接保存稳定 ID，显示目标笔记的当前标题。写成 `[[ID|显示文字]]`、先选中文字再插入，或之后直接编辑链接文字，都能保留自己的措辞；手动文字在目标改名后不会被覆盖。Markdown 源码保留 `[[ID]]`，可视化编辑器和预览显示标题。没有匹配结果时，选择**新建实体**创建并链接笔记。在可视化编辑器和预览中悬停链接，可查看标题、类型、上级和反向链接数；反向链接列出每一处引用段落。上下级用“上级”，关联用双链。

### 标签

在条目的标签区域使用**推荐标签**和**标签管理**。**推荐标签**根据相关文献和已有词汇给出主题，确认后添加。**标签管理**把相近名称分组并说明匹配原因，可核对合并、重命名或格式化标签。排除标签支持名称、`*` 通配、`@colored` 和 `@auto`；例如 `@colored, reading*` 隐藏彩色标签和以“reading”开头的名称。规则作用于推荐、标签管理和笔记展示。

### 相似条目

在条目的**相似条目**区域查看相关文献。结果在本地加载，滚动时继续出现，包括没有全文的论文。macOS 上的语义检索会下载所需文件。

### 关系图

在知识库工具栏打开关系图；选中笔记后点**在关系图中定位**查看局部关系。**结构**按父子关系连接，**引用**按双链连接。可按笔记类型或关系筛选，并在全部笔记和局部关系之间切换。节点颜色来自设置中的 Group 标签。

### 阅读

**边读边记**打开 PDF 并在 Zotero 侧栏选中笔记。**原生笔记使用知识库编辑器**控制侧栏、笔记标签页和笔记窗口是否使用此编辑器。macOS 使用 Command-Shift-X（其他系统为 Ctrl-Shift-X）框选图片到剪贴板。页码框左侧的知识库按钮打开论文的文献笔记，Command/Ctrl＋点击可新建。**在文库中显示**定位无论文来源笔记使用的个人知识父条目。

### 外观

在设置中选择 Minimal、Bear 或备忘录，以及浅色或深色。关闭仍有未保存内容的笔记时，可选择保存、取消或丢弃修改。
