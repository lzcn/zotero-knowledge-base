在 Zotero 中管理笔记、整理标签、发现相似条目。需要 Zotero 10。

## 功能

在**工具**菜单、文献库或 PDF 工具栏中打开**知识库**。

### 笔记

用富文本或 Markdown 编辑 Zotero 笔记，修改自动保存。在笔记上方设置来源、上级和标签；上级旁的铅笔可搜索笔记，底栏显示类型和可编辑 ID。类型可选文献、原子、思考或实体，模板在设置中管理。笔记继承来源和上级的标签。**增强 → 数学预览**在笔记卡片和 PDF 批注中显示公式。

### 双链

输入 `[[` 查找笔记；↑/↓ 选择，Enter 或 Tab 插入，Escape 关闭。链接保存稳定 ID，显示当前标题。写成 `[[ID|显示文字]]`、先选中文字再插入，或之后直接编辑链接文字，都能保留自己的措辞；手动文字在目标改名后不会被覆盖。Markdown 源码保留 `[[ID]]`，可视化编辑器和预览显示标题。没有匹配结果时，**新建实体**会创建并链接笔记。在可视化编辑器和预览中，悬停链接可查看标题、类型、上级和反向链接数；反向链接列出每一处引用段落。上下级用“上级”，关联用双链。

### 标签

**推荐标签**复用相关文献的主题。**标签管理**整理名称变体和语义匹配，合并或格式化标签，并支持 `@colored, reading*` 等排除规则。规则作用于推荐、标签管理和笔记展示。

### 相似条目

在本地查找相关文献，滚动时自动加载。macOS 上的语义检索会下载所需文件。

### 图谱

**结构**按父子关系连接，**引用**按双链连接。可按笔记类型或关系筛选；节点颜色来自设置中的 Group 标签。

### 阅读

**边读边记**打开 PDF 并在 Zotero 侧栏选中笔记。**原生笔记使用知识库编辑器**控制侧栏、笔记标签页和笔记窗口。macOS 使用 Command-Shift-X（其他系统为 Ctrl-Shift-X）框选图片到剪贴板。页码框左侧的知识库按钮打开论文的文献笔记，Command/Ctrl＋点击可新建。**在文库中显示**定位无论文来源笔记使用的个人知识父条目。

### 外观

提供 Minimal、Bear 和备忘录，均支持浅色与深色。关闭仍有未保存内容的笔记时，可选择保存、取消或丢弃修改。
